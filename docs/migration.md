# 多来源版本迁移

## 首次启动

如果检测到旧排列设置、Codex 路径设置、Claude 快照或原 GLM 条目，会创建 Codex、Claude、GLM 三个默认连接，保留原排列和常驻顺序。新安装没有这些旧配置时，从空连接列表开始；在菜单“连接设置…”中选择来源。

新配置位于：

```text
~/Library/Application Support/CodexMeter/connections.json
~/Library/Application Support/CodexMeter/usage.sqlite
```

前者保存连接元数据、日志目录、常驻项与价格；后者保存用量事件、额度快照和导入进度。文件按 owner-only 权限写入。密码、Token 和 Cookie 不写入上述文件。

配置无法解码或版本过新时保留原文件，不用空配置覆盖。请先备份，再修复或使用兼容版本。数据库升级使用版本号和事务，版本比应用更新时停止历史读写，不重建覆盖。

## 原有三家

- Codex 本机模式继续交给当前 app-server 查询；额外账户改用独立 OAuth 文件／Token。设置路径可以选择可信的 Codex 可执行文件。
- Claude 优先使用不消耗推理额度的 usage 路径。旧长期 Token 仅有 inference 权限时，需在连接中明确打开付费探测才会使用；不会因免费路径失败自动花费额度。
- GLM 默认连接保留旧专属条目读取。需要重新授权或转入新存储时，在连接编辑器点击“迁移旧 GLM 凭据”，然后保存。旧条目不删除，便于兼容原版本。
- Claude 旧快照仅用于兼容恢复；通用历史随后按连接和凭据修订存储。更换身份／配置不会恢复旧修订的快照。

## 多账户与统计

同一来源可添加多个命名连接。一个只能读取当前 CLI 的模式不能伪装成多个独立账户；额外账户需要自己的 profile 或凭据。增加的来源默认不占用常驻位置，最多固定三项。

日志采集默认关闭。在“用量统计 → 采集与价格设置”开启后，读取选定目录的用量字段。默认保留 90 天；可以设置 30–730 天。账户归属默认未知，仅为确实单一账户的目录指定绑定。

模型价格可手工维护，或主动从 models.dev 补充 OpenAI、Anthropic、Google 目录价格。已有配置优先；目录中双零价格不自动认定为免费，确知免费时可手工配置。价格保存后可重新导入日志来补全未计价记录；既有已计价记录保留其版本。

统计数据集分为本地日志、已有工具导出、服务商账单。前两类按本机时区；OpenAI／Anthropic 组织账单按原始 UTC 日分组，未按模型拆分的费用独立显示。更换凭据后仅显示当前修订的账单，旧行按保留期保存；不同 Key 共享组织权限时需避免重复添加同一账单范围。

“清除本地历史”删除统计与额度历史，保留连接、凭据和导入位置，避免立刻自动重导已有文件。“重新导入日志”重置位置，重新读取原文件，并按稳定 ID 去重。原工具日志始终保留。
