# 编写和维护来源适配器

## 结构

- `MonitorDomain.swift`：来源账户、能力、标准化指标与快照。
- `SourceRegistry.swift`：来源目录、认证方法、配置字段、区域和发现入口。
- `MonitorAdapter.swift`：复用现有客户端，调度原生来源和声明式查询。
- `ToolProviders.swift` / `CloudProviders.swift`：各来源的协议和签名，不能依赖具体界面。
- `MonitorEngine.swift`：账户级刷新、最大 4 个并行读取、退避、取消和旧请求隔离。
- `MonitorStorage.swift`：配置和应用专属凭据；`UsageHistory.swift`：版本化 SQLite 历史。
- `ConnectionsWindow.swift` / `StatisticsWindow.swift`：通用设置与统计；`NotchUI.swift`：最多三项常驻及全部连接详情。

新增来源时提供稳定 ID、名称、真实能力、登录前提和实际读取实现；接入调度与注册表。不为新来源在 AppDelegate 中新增专用 loader、菜单、字段或刷新代码。

界面文案和错误信息用英文写并通过 `L()` 查表，同步更新中文翻译，详见 [CONTRIBUTING.md](../CONTRIBUTING.md)。指标 ID 不能由翻译后的文案生成，否则切换语言后用户选择的主指标会失效。

## 数据契约

返回 `MonitorSnapshot`，携带当前连接的 `accountID` 和 `sourceID`。`MonitorMetric` 的含义：

- `quota`：`value` 是剩余量；有可靠的 `total` 才能计算百分比。周期与重置时间仅使用服务商证据。
- `balance`：可消费余额；保留币种和可能的欠费，不以 0 代替未知。
- `tokens`：明确时间范围内的用量计数；缓存输入与新输入不重叠。
- `cost`：明确原始币种和时间范围的费用；服务商返回值、已有工具结果、价格估算分别标识。

可以有任意数量的窗口，不把所有来源强制改成 5 小时／周。MCP、模型子池、Credits 等保留自己的名称。缺失数据省略；接口失败抛错，由账户状态保留最后成功快照及其时间。

不要在来源中持久化完整响应、提示词或凭据，也不要自行往 AppDelegate 注入 UI。内置请求使用固定服务商域名、临时 HTTP 会话、大小／时间边界，拒绝重定向。认证失效应提示重新连接。

## 凭据与账户

每个连接具有独立 UUID 和凭据修订号。账户或凭据变化后，旧请求不能覆盖新状态，旧修订的快照不能作为当前缓存恢复。添加独立账户时使用独立凭据／profile，不能改写其他工具默认登录态。

应用专属条目位于 `Meterline Connections`，旧的 `CodexMeter Connections` 只作读取回退。后台读取不得弹授权：应用自己的条目一律通过 `AppKeychain` 读取，不要调用 `/usr/bin/security`，它读取应用创建的条目时会弹密码窗口。用户保存时只信任本应用，不允许所有应用。旧 GLM 条目的兼容路径保留，显式迁移时复制到新连接专属条目，不删除旧条目。

## 自定义 HTTP 查询

普通用户通过界面配置 `CustomQuery`。支持：

- HTTPS GET／POST；HTTP 需单独启用，Magpie 的普通 HTTP 集成限本机地址。
- 请求头中使用 `${token}`、`${cookie}`、`${userID}`；认证字段从钥匙串替换。
- 对象路径和数组索引，例如 `data.balance`、`data.items[0].remaining`。
- 指标数组路径、数组项名称路径、数值缩放、剩余／已用／百分比方向。
- ISO 8601、Unix 秒或毫秒重置时间；可填写已知周期分钟数。

总量未知时保持数值展示。缩放系数只做乘法，不计算任意表达式。没有 JavaScript、Shell、任意插件或远程代码执行。

数组名称路径提供稳定身份：数组调换顺序时保持相同指标 ID；名称缺失或重名只能使用索引／出现次序，不能保证跨重排身份。预览展示映射结果以及最多 120 个响应字段的路径和类型，不显示完整响应内容；映射失败时仍可参考结构。

组织账单可在快照的 `usageEvents` 返回真实日期的日聚合，使用 `.provider` 数据集、账户 UUID 与凭据修订组成稳定 ID。它们与本地／导入请求分开，不将日聚合数当作请求次数；快照缓存剥离该事件数组。账单金额允许后续修正，不能只取历史最大值。

示例：New API 的账户额度采用 `data.quota`，缩放系数 `0.000002`，单位 `USD`。请求头采用 `Authorization: Bearer ${token}` 和 `New-Api-User: ${userID}`。实际部署单位不同应调整映射。

配置模板由界面导出，包含版本、来源、名称、非敏感查询配置；不导出账户 UUID、钥匙串值或本地凭据路径。模板导入后默认停用，用户配置认证、检查目标地址并保存后再开启。

## 样例和检查

使用合成或彻底脱敏的响应。覆盖认证失败、返回结构变化、未知周期、未知余额、数组顺序变化、取消和多账户隔离。

用量导入还需覆盖：累计计数转增量、同请求多段流式结果、文件轮换、半行写入、SQLite 迁移、重复导入、不同币种和价格版本。不要把“支持模型路由”计作“能查询额度”。

常用检查：

```sh
swift test
./build-app.sh
```

真实账户和界面检查另行记录，不能由这些命令代替。PR 说明实际执行过的检查及未执行项，不上传账号信息、密钥或完整会话文件。
